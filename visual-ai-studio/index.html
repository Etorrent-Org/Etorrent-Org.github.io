INSTALL

Un installateur Windows, puis Studio Visuel.

La release officielle fournit l'installateur, le package Studio Visuel et les empreintes SHA-256. Python, Git et Docker ne sont pas nécessaires côté utilisateur final.

  1. Télécharger Visual-AI-Studio-Setup-0.1.1.exe.
  2. Lancer l'installateur Windows.
  3. Préparer Studio Visuel dans ChatGPT à partir du package fourni.
  4. Créer un premier brief et démarrer le workflow.
