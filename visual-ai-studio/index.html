Fonctionnalités

Un workflow simple, volontairement lisible.

Visual AI Studio garde l’application locale légère : elle structure le brief, prépare le prompt de lancement, importe les créations, les présente dans une galerie et laisse l’utilisateur valider avant l’export.

01

Créer le brief

Nom du projet, campagne, audience, style, idée, texte dans l’image, dimensions, ratio et contraintes créatives.

02

Préparer Studio Visuel

L’application produit un prompt de lancement structuré sans dupliquer la logique du Skill de l’agent.

03

Choisir le mode

Pinterest, Instagram ou Autre / personnalisé selon le canal et les contraintes de sortie.

04

Importer les résultats

PNG, JPG, JPEG, WebP, Markdown, TXT et JSON peuvent être réunis dans un même projet.

05

Valider humainement

Plusieurs images peuvent être contrôlées dans une galerie avant l’action explicite « Je valide ce résultat ».

06

Exporter localement

Le projet validé est exporté dans un dossier dédié, sans dépendance cloud obligatoire.

Workflow

Visual AI Studio et Studio Visuel ont chacun leur rôle.

L’application Windows ne génère pas directement l’image. Le passage par ChatGPT reste manuel et transparent, ce qui permet de garder la maîtrise de chaque étape.

01BriefStructurer l’intention, le canal et les contraintes.
02Prompt de lancementCopier le contexte préparé par l’application.
03Studio VisuelReformuler, construire la direction artistique et générer.
04ValidationImporter les fichiers et contrôler les résultats.
05ExportConserver les livrables localement.

Interface

Une interface métier sombre, compacte et orientée action.

La v0.1.0 privilégie quelques écrans explicites plutôt qu’une console technique : projets, brief, préparation Studio Visuel, validation et paramètres.

Installation Windows

Un installateur, pas d’environnement technique à préparer.

La Release officielle fournit l’installateur Windows, le package Studio Visuel et les empreintes SHA-256.

  1. Télécharger Visual-AI-Studio-Setup-0.1.0.exe.
  2. Lancer l’installateur Windows.
  3. Installer ou préparer séparément Studio Visuel dans ChatGPT à partir de studio-visuel-agent.zip.
  4. Lancer Visual AI Studio depuis le menu Démarrer.
  5. Créer un premier brief puis utiliser « Préparer pour Studio Visuel ».

Positionnement

Local-first, humain dans la boucle, sans API imposée.

Visual AI Studio ne nécessite aucune clé API OpenAI. Les projets et fichiers de travail restent locaux ; ChatGPT et Studio Visuel interviennent uniquement lorsque l’utilisateur choisit de poursuivre la création.
