OVERVIEW

Du brief au livrable, avec contrôle humain.

Visual AI Studio structure la demande et les livrables ; Studio Visuel et IA-Art restent séparés de l'application et travaillent dans ChatGPT.

CAPABILITIES

Trois responsabilités, clairement séparées.

01

Cadrer

Formaliser objectif, audience, style, texte, format et contraintes. Le mode Instagram gère de 1 à 10 visuels principaux en 1080 × 1350.

02

Contrôler

Importer les fichiers produits, vérifier leur intégrité, les parcourir dans une galerie locale et conserver une validation humaine explicite.

03

Exporter

Télécharger l'archive du projet validé ou transmettre le paquet au webhook n8n existant, sans clé API OpenAI dans l'application.

WORKFLOW

Une application web, un agent conversationnel séparé.

Le dépôt ne contient plus l'ancienne application desktop PySide6 ni sa chaîne Windows. Le runtime courant est React/Vite + FastAPI/Python, SQLite et Docker Compose.

INSTALL

Docker Compose, puis ouverture du studio web.

Créer le fichier .env depuis .env.example, construire les conteneurs et ouvrir le port local 3093.

  1. Cloner Etorrent-Org/visual-ai-studio.
  2. Créer .env à partir de .env.example.
  3. Lancer docker compose up -d --build.
  4. Ouvrir http://localhost:3093.
