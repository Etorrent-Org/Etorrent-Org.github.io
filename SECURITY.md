# Security Policy

Ce dépôt est public et sert directement le portail GitHub Pages Etorrent-Org.

## Règle principale

Ne jamais y stocker :

- mot de passe ou token ;
- fichier `.env` ;
- clé privée ou secret de signature ;
- cookie ou session navigateur ;
- licence client ;
- sauvegarde privée ;
- donnée client ou information confidentielle.

Les pages publiques doivent uniquement référencer des informations, liens et ressources destinés à être exposés publiquement.

## Liens externes

Avant publication, vérifier les liens vers les dépôts, releases, images et adresses de contact afin d’éviter les références obsolètes ou privées.

## Signaler un problème

Pour un problème de sécurité, éviter de publier des détails exploitables dans une issue publique. Utiliser le mécanisme de signalement privé de GitHub lorsqu’il est disponible.
