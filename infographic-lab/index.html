Infographic Lab

Transformer un texte en visuel clair, puis garder la main : structure IA avec Mistral Vibe, rendu AntV ou SVG local, édition bloc par bloc, templates, styles et exports.

Télécharger la V1Dépôt GitHub

V1 complète

Une chaîne courte : texte, structure, visuel, édition, export.

Infographic Lab reste local-first et évite la logique de plateforme. Le moteur IA ne dessine pas du HTML libre : il renvoie un JSON contrôlé, puis l'application décide du rendu.

01

Structurer avec Vibe

Le texte source devient un JSON canonique court, validé avant rendu et réutilisable pour plusieurs variantes.

02

Choisir le bon visuel

Processus, timeline, liste, comparaison, pyramide, entonnoir, Iceberg, Cycle, Sankey simple et autres variantes compatibles.

03

Éditer localement

Titre, sous-titre, blocs, ordre, pictogrammes, couleurs et densité peuvent être modifiés sans nouvel appel IA.

04

Retoucher un bloc

Vibe peut réécrire uniquement l'élément ciblé, avec avant/après et annulation locale en une étape.

05

Sauvegarder le projet

Le JSON projet conserve le texte source, le style, la variante, les pictogrammes et l'apparence sans base de données.

06

Exporter

SVG vectoriel, PNG haute résolution ou HTML autonome contenant le visuel final.

Installation locale

Un ZIP, Docker Desktop et une clé Mistral Vibe.

La release contient l'application complète. Aucun compte Infographic Lab, aucune base de données et aucun service de stockage ne sont nécessaires.

  1. Télécharger Infographic-Lab-v1.0.0.zip depuis GitHub Releases.
  2. Extraire l'archive puis copier .env.example vers .env.
  3. Renseigner MISTRAL_API_KEY.
  4. Lancer .\START-INFOGRAPHIC-LAB.ps1 -Build.
  5. Ouvrir http://127.0.0.1:3091.

Architecture maîtrisée

Le runner Vibe reste derrière l'application.

Le navigateur parle uniquement à la passerelle locale. Le runner Vibe reste sur le réseau Docker interne, son port 7020 n'est pas publié et les réponses IA sont validées avant d'atteindre le moteur de rendu.
