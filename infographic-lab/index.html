OVERVIEW

Une seule structure, plusieurs représentations.

L'IA structure l'information dans un modèle contrôlé. Les moteurs de rendu locaux transforment ensuite ce modèle sans demander à l'IA de générer librement du SVG ou du HTML.

TWO TRACKS

Stable et préversion restent distinctes.

Stable · 1.0.0

Infographie éditable

Vibe structure le texte, AntV ou le moteur SVG local dessine, puis l'utilisateur édite et exporte localement. Runtime sur le port 3091.

Augmented · V2

Napkin light local-first

Gateway Vibe / Codex, Infographie, Mermaid, Mindmap, Markdown, catalogue de représentations business, Quality Gate et Publication Pack. Préversion sur le port 3092.

Contrôle humain

Pas d'invention de données

Les graphiques chiffrés ne sont proposés qu'avec des valeurs explicites. Une série incomplète reste incomplète.

CAPABILITIES

Le produit sépare structuration et rendu.

01

Structurer

Vibe ou Codex produit un modèle JSON canonique contrôlé par la passerelle locale.

02

Représenter

AntV et les moteurs SVG spécialisés produisent processus, matrices, SWOT, KPI, graphiques, hiérarchies, cycles et autres formats utiles.

03

Décliner

Le même modèle peut alimenter Infographie, Mermaid, Mindmap et Markdown sans repartir de zéro.

INSTALL

Deux Docker Compose, deux usages.

  1. Pour la stable, utiliser .\START-INFOGRAPHIC-LAB.ps1 puis ouvrir http://127.0.0.1:3091.
  2. Pour Augmented, utiliser docker compose -f docker-compose.augmented.yml up -d --build.
  3. Ouvrir ensuite http://127.0.0.1:3092.
