Politique de confidentialité

Cette politique décrit le fonctionnement du site public H9 Factory et de sa démonstration interactive exécutée dans le navigateur.

En bref

  • Aucun compte utilisateur
  • Aucun formulaire transmis
  • Aucun appel IA dans le mock
  • Aucun cookie propre
  • Exports générés localement

1. Responsable

H9 Factory est un projet présenté par Erwann Torrent sous le compte GitHub R1-Torrent. Les demandes publiques peuvent être déposées dans le suivi GitHub du portail.

2. Objet du site

Le site explique le fonctionnement de H9 App Factory et propose une simulation du parcours « Cadrage Express ». Il ne donne pas accès au runtime Docker, aux runners CLI, à PostgreSQL ni aux applications privées de l’écosystème H9.

3. Données saisies dans le mock

Les textes saisis ou modifiés dans la démonstration restent dans la page ouverte. Le script ne les envoie à aucun serveur et ne les conserve ni dans un cookie, ni dans un stockage local. Fermer ou recharger la page réinitialise la démonstration.

4. Exports

Les exports JSON, Markdown et HTML du mock sont assemblés par le navigateur à partir du résultat simulé. Le téléchargement est déclenché directement sur l’appareil de l’utilisateur, sans transfert préalable vers H9 Factory.

5. Intelligence artificielle

La démonstration publique n’exécute aucun modèle d’intelligence artificielle. Les mentions de Codex CLI et Mistral Vibe CLI décrivent les adaptateurs disponibles dans l’environnement local du framework ; elles ne constituent pas des connexions actives depuis ce site.

6. Cookies et mesure d’audience

Le site ne dépose aucun cookie propre et n’intègre aucun outil de mesure d’audience. GitHub Pages assure l’hébergement statique et peut traiter les informations techniques nécessaires à la livraison de la page selon ses propres conditions.

7. Sécurité et secrets

Aucun jeton, identifiant CLI, accès PostgreSQL ou secret d’administration n’est intégré au site. Le runtime H9 complet est destiné à un environnement local et maîtrisé ; il ne doit pas être exposé tel quel comme service public multi-utilisateur.

8. Services tiers

GitHub applique ses propres conditions et politiques de confidentialité pour l’hébergement du dépôt et de GitHub Pages. Cette politique couvre uniquement le comportement du site H9 Factory et de son script de démonstration.

9. Contact

Pour signaler une erreur, demander une précision ou exercer une demande liée au site public, utilisez le suivi des demandes du portail.
